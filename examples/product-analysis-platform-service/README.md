# Produktanalys för Plattformstjänst – steg 31

Syntetiskt native-v2-scenario som verifierar att en realiseringsneutral Plattformstjänst kan analyseras mot flera marknadsprodukter via `can_realize` utan att marknadsbedömningen blir faktisk organisationsstatus.

Scenariot använder `PLS-261 Applikationskörning` och tre syntetiska produkter med rollerna `primary`, `partial` och `supporting`. `actual-state` är avsiktligt tomt.
