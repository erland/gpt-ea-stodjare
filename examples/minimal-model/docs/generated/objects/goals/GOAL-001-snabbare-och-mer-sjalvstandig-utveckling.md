# Snabbare och mer självständig utveckling

- **ID:** `GOAL-001`
- **Objekttyp:** `goal`
- **Status:** `candidate`

## Beskrivning

Operativa utvecklingsområden ska kunna utveckla och förändra IT-stöd med kortare ledtid.

## Målinformation

- **Måltillstånd:** Utvecklingsområden kan använda gemensamma IT-förmågor utan projektspecifik grundetablering.
