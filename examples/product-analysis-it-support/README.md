# Produktanalys för IT-stöd – Ordbehandling

Detta är ett syntetiskt native-v2-scenario för att stresstesta att `Product` och `can_realize` fungerar för applikationsnära IT-stöd och inte bara för plattformsområdet.

Scenariot skiljer strikt mellan:

1. **Conceptual:** `ITS-251 Ordbehandling` beskriver ett produktoberoende behov med embedded functions.
2. **Market reference:** tre syntetiska marknadsprodukter har källstödda externa påståenden om sina egenskaper.
3. **Realization potential:** `can_realize` använder rollerna `primary`, `partial` och `supporting`.
4. **Actual state:** endast en produkt har separat organisationsspecifik evidens för faktisk användning.

Produktnamnen och leverantörskällorna är medvetet syntetiska. Syftet är att testa modellsemantik, inte att göra en tidsberoende marknadsjämförelse.
