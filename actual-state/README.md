# Actual state

Detta lager innehåller verifierad organisationsspecifik information om faktisk status.

En Produkt kan refereras direkt, exempelvis genom `product_in_use`. Det krävs ingen separat kärnobjekttyp för "Actual Platform Offering".

Viktigt:

- vald produkt är inte automatiskt produkt i drift,
- produkt i drift är inte automatiskt ett organisatoriskt erbjudande,
- organisatoriskt erbjudande måste uttryckas separat,
- extern marknadsevidens räcker inte ensam för att verifiera faktisk organisationsstatus.
