# Market reference

Detta lager innehåller källstödda marknadspåståenden. Det är **inte** kanoniskt för organisationens faktiska val eller användning.

- Marknadskapabilitet innebär inte faktisk användning.
- `Product --can_realize--> ...` beskriver potential, inte införande.
- Flytta inte ett marknadspåstående till `actual-state/` utan ny organisationsspecifik evidens.
