# Rev80 compatibility reference

Denna katalog beskriver den rekonstruerade metamodellen för `it-formagemodell-del3-rev80`. Den innehåller ingen kopia av projektets kanoniska EA-data.

- `metamodel.yaml` – maskinläsbar rekonstruktion.
- `extension-inventory.yaml` – inventering av supporting-YAML.
- `source-fingerprints.yaml` – fingerprint för centrala rev80-källfiler.
- `metamodel-reconstruction.md` – människoläsbar analys.
