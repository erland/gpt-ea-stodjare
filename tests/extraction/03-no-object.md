# Test 03 – inget meningsfullt EA-objekt

## Syntetiskt underlag

> Workshoppen genomfördes på tisdag eftermiddag. Fem personer deltog och mötet avslutades klockan 15.30.

## Förväntat analysbeteende

- Ingen av v1:s EA-objekttyper kan beläggas enbart av texten.
- Ingen modelländring rekommenderas.
- "Workshop", "tisdag" eller "fem personer" ska inte omvandlas till EA-objekt.
